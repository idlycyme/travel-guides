# travel-guides

Offline-first travel guide PWAs, one folder per trip, served with GitHub Pages.

- `italy/` — 2026 Italy (Rome, Naples, Tuscany, Cinque Terre, Florence, Venice, Milan). Live: https://idlycyme.github.io/travel-guides/italy/
- `_template/` — copy this to start a new guide. `README.md` inside documents the data schema, tools and the build workflow.

Each guide is plain HTML + one `data.js`; no build step, no framework. Images from Wikipedia / Wikimedia Commons (see `img/*/credits.json`), map tiles © OpenStreetMap contributors.
